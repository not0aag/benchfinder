# mobile

BenchFinder Expo app. CNG workflow: `android/` and `ios/` are generated by `expo prebuild` and never committed.

```bash
pnpm start                # dev server (needs a dev client build, not Expo Go)
pnpm prebuild             # regenerate native projects
eas build --profile development --platform android
```

Routes live in `app/` (expo-router). Feature code lives in `src/features/` as vertical slices. See `BENCHFINDER_ARCHITECTURE.md` at the repo root, section 8.
